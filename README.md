The objective of this task is to build and evaluate a machine learning model that can predict outcomes based on a given dataset. For this project, I used the PIMA Indian Diabetes dataset, which contains health-related features to predict whether a person has diabetes.

The analysis involved the full machine learning pipeline:

Data preprocessing (handling missing values, scaling features)

Feature selection based on correlation

Model training using Logistic Regression

Model evaluation using accuracy, precision, recall, F1-score, confusion matrix, and ROC-AUC
